# reach-without-claude

Checks that the slash commands, skills, and specialists are reachable as text by an agent that is not Claude Code.

A command is a prompt, a skill is instructions, an agent is a role definition. Claude Code loads them
natively; everything else reads them. `acp commands`, `acp command <name>`, `acp skills`,
`acp skill <name>`, `acp agents`, and `acp agent <name>` are that path, and `AGENTS.md` names it.
